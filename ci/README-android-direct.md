# Пряма Android-збірка Rockbox

Цей workflow збирає нативний Android-застосунок Rockbox (`android` target), а не `androidsim` із корпусом та кнопками пристрою. APK містить framebuffer Rockbox і тему Z1Music_Green.

Цільова архітектура — `arm64-v8a`, мінімальна Android версія — API 21. Поточний builder спирається на старий NDK r16b GCC toolchain для цього історичного Android target; наявність успішного compile сама по собі не гарантує запуск на конкретній прошивці. Workflow перевіряє ABI в APK і вирівнювання ELF PT_LOAD сегментів для 16 KB сторінок.

Rockbox canvas лишається 1080×1920, як і надана тема. Java framebuffer створює canvas саме такого розміру, пропорційно масштабує його до Android Surface і центрує, щоб не обрізати елементи й не спотворити їх. За відмінного співвідношення сторін будуть чорні поля; повний адаптивний редизайн Z1Music_Green — окрема робота.

На першому запуску застосунок просить доступ до сховища й створює початкову конфігурацію теми. Доступ до музики, роботу торкань і аудіо потрібно перевірити на реальному пристрої, особливо на сучасному Android. Перед заміною старої версії збережіть музику та конфігурацію; через різні підписи Android може вимагати видалення попередньої версії.
